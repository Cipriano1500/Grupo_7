## 📋 Descrição do Projeto

Este projeto foi desenvolvido implementando uma **Deep Neural Network (DNN)** e **Regressão Logística** construídas **exclusivamente com NumPy**, incorporando melhorias avançadas de deep learning.

### 🎯 Características Avançadas Implementadas:

- **✅ Função de Ativação ELU (Exponential Linear Unit)**  
  Melhor fluxo de gradientes e redução do problema de vanishing gradient

- **✅ Inicialização Adaptativa de Pesos (He/Xavier Initialization)**  
  Inicialização inteligente dos pesos para melhor convergência

- **✅ Learning Rate Decay Automático**  
  Ajuste dinâmico da taxa de aprendizagem durante o treino

- **✅ Early Stopping**  
  Prevenção de overfitting através de parada antecipada

- **✅ Otimizador Adam Implementado do Zero**  
  Algoritmo de otimização adaptativo completo em NumPy

- **✅ Pré-processamento e Vetorização TF-IDF**  
  Transformação de texto em features numéricas

- **✅ Avaliação Completa com Métricas**  
  Accuracy, Precision, Recall, F1-Score e Matriz de Confusão
